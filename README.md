# Phishing Simulation: Quishing (QR Code Phishing)

## Overview
This repository contains a comprehensive security awareness training package demonstrating a QR code phishing ("quishing") simulation. Designed as part of cybersecurity awareness operations, this project utilizes a just-in-time educational landing page to instantly inform users who scan test codes about the indicators they missed, reinforcing secure behavior without compromising data.

---

## Project Components
* **Just-in-Time Landing Page (`index.html`):** A responsive, dark-themed HTML/CSS web page displaying an immediate awareness notice, warning sign breakdowns, and future preventative tips.
* **Email Template & Report:** (Coming Soon) Documentation outlining the simulated phishing lure, unexpected PDF attachment context, and urgency indicators.
* **Video Demonstration:** (Coming Soon) A walkthrough showcasing the simulation workflow from QR code scan to educational landing page display.

---

## Warning Signs Addressed
1. **Urgent Request:** Artificial pressure forcing immediate action without critical evaluation.
2. **Unexpected Attachments:** Unsolicited documents or files out of the ordinary context.
3. **QR Code Vectors (Quishing):** Bypassing standard desktop email security banners by forcing interaction through mobile devices.
4. **Lack of Verification:** Failing to independently cross-check unusual requests via trusted internal channels.
